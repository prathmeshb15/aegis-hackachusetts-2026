# AEGIS product steering

AEGIS is an experimental predictive safety supervisor for a 2D autonomous warehouse robot. It is NOT safety-certified software and cannot control actual robots. Focus on real, reproducible experiments, clarity, and working user interactions.

Hackachusetts track: Robotics & Hardware. Mandatory: meaningful Kiro development work, `.kiro` directory committed at repository root, public repository, under-three-minute publicly hosted demo video, accessible working project, written description and genuine account of Kiro features actually used. Never claim these are already done.

Priorities: runnable demonstrator; predictive safety interventions and recovery; repeatable comparison against the same baseline; clean UI; tests; straightforward setup. Avoid unsupported claims of learned AI, calibrated probability, guarantees, hardware safety, real sensing, or physical validation.
